LEGACY Pro Wrestling 1.0 — Runtime Audit Cleanup

Completed:
- Deleted the unfinished Money in the Bank / ladder-match mode from JavaScript and CSS.
- Restored Specialty Matches to Last Man Standing only.
- Deleted the separate final-hotfix runtime file and removed it from index.html.
- Replaced the competing Throwdown-specific click interception with one canonical Career Begin route.
- The canonical Begin route always enters the current Career day engine exactly once.
- Removed obsolete patch validation files and superseded root-level patch notes.
- Updated the service-worker cache identifier.

Important architecture note:
The game still contains historical internal function names such as gauntletLive* because current saves and many current systems depend on them. They are no longer exposed through a separate hotfix click layer in this build. A safe physical rename/removal of every internal identifier requires a dedicated engine rewrite and save-migration pass; blindly deleting those helpers would break Career mode.
